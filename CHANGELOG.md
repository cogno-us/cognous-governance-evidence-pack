# Changelog

## Unreleased

- Repins the F5b generation's hard-coded peer revisions to the remediated tuple: runtime `4a83b175d2ef0e65a7ee22a0513bb94a5fdf3a6f` (was `e20f92e1`) and Replay `0cfe7a6319930bccad3e9027a1dfbe3d6e29d657` (was `79ba16d4`). Replay's `MOLTBOT_F5B_REVISION` equals the pack's runtime literal. Manifest and control-plane revisions are unchanged.
- Replay semantic validation now also requires the retained bundle's `import_reports` and `semantics` to equal a fresh accepted reconstruction (previously only `records`, `links`, `commitments`, `producer_profiles` and `status` were compared). A bundle whose import reports or findings were dropped, or whose semantics were promoted (`independent_effect_verification`, `destination_observation`), is now rejected with `retained Replay import_reports|semantics differs from accepted reconstruction`. Qualification F-06/F-12 (SCN-D08, SCN-C23).
- Adds the F5b security-runtime generation (CP `a34c3dc2`, runtime `e20f92e1`, Replay `79ba16d4`, Manifest `2c36bcd0`) with transformation `agep-manifest-reconstruction-import/0.3.6-security-runtime-f5b-candidate`, beside the unchanged `996baeb4`/`fd6b76fa`/`3601fb21`/`e385f8c1` generation. Executor and Manifest revisions must belong to the same generation as the Control Plane revision; cross-generation bundles are rejected. See `docs/security-runtime-f5b-profile-20261016.md`.
- `build_evidence_pack_from_files` (and so `agep import`) now reads both input files through the shared admission parser instead of `json.load`. File import therefore also applies the admission byte budget (8 MiB), depth limit (32) and node limit (100,000 objects/arrays), and rejects duplicate JSON keys and the `NaN`/`Infinity`/`-Infinity` literals. Out-of-range numeric literals such as `1e999` are still accepted and parse as floating-point infinity.
- The Markdown renderer labels review status, review decisions, signature, redaction and validation fields "(asserted, unverified)". The `examples/producer-v2/*.md` goldens are regenerated for these labels.
